# 平台规格与安全区

> 出了海报，要投放到哪个渠道？**先查表再画**：每个平台的画幅、像素尺寸、以及
> **会被 UI 遮挡的安全区**都不一样。选错画幅 = 白干一轮；踩到安全区 = 关键信息被盖。
>
> 借鉴自同类项目（`alonw0/web-asset-generator` 的平台规格表、`gbro-cover-design` 的
> 固定画幅 + 安全区定义），并补上中文平台的遮挡规律。

## 一、画幅 / 尺寸速查

| 渠道 | 比例 | 建议像素 | 本仓内置格式 |
|---|---|---|---|
| 打印 / 张贴 | A4 210×297mm | 2480 × 3508 @300dpi | `poster-a4` |
| 易拉宝 / 展架 | 80×200cm | 3150 × 7874 @100dpi | `poster-banner` |
| 朋友圈（单图） | 1:1 或 3:4 | 1080×1080 / 1080×1440 | `poster-square` / `poster-social` |
| 公众号首图（超宽） | 2.35:1 | 900 × 383 | 用 `poster-wide` 改比例，或按 2.35:1 建新模板 |
| 公众号文章内配图 | 16:9 | 1080 × 608 | `poster-wide` |
| 小红书封面 / 配图 | 3:4 | 1242 × 1656（常用 1080×1440）| `poster-social` |
| 视频号 / 抖音 / 快手 | 9:16 | 1080 × 1920 | `poster-story`（安全区已闸门化）|
| 微博 / 知乎配图 | 16:9 | 1920 × 1080 | `poster-wide` |
| 网站 hero / 视频封面 | 16:9 | 1920 × 1080 | `poster-wide` |
| Open Graph（FB/LinkedIn） | 1.91:1 | 1200 × 630 | 未内置 |
| X / Twitter 大图卡 | ~1.91:1 | 1600 × 900 | 未内置 |

> 本仓 `example/` 内置 5 种；其余比例按同样的「数据 + tokens + 模板」产线加一个
> `templates/poster-*.typ` 即可（新格式记得同步 `scripts/preflight.py` 的 `FORMATS`、
> `build` 脚本、`check_qr.py` 的列表 —— 否则会静默漏检）。

## 二、安全区（会被平台 UI 遮住的地方，关键信息别放）

| 平台 | 遮挡区 | 说明 |
|---|---|---|
| 抖音 / 视频号 / 快手（竖屏）| 顶部 ~10%、**底部 ~15%**、右侧 ~15% | 状态栏、标题与操作按钮、右侧按钮列 |
| 小红书 | **底部 ~12%** | 标题行、跳转按钮 |
| 微信公众号首图 | 右下角 | 播放按钮 / 来源标记可能压住 |
| 朋友圈单图 | 无明显遮挡 | 但**信息流里会被裁成方形缩略图** → 主体与标题压中心区 |
| 易拉宝 | **底部 ~30cm** | 展架底脚与卷边遮挡 |
| 印刷（A4 等）| 出血 3mm、安全线 5mm；外框离页边 **≥10mm**；正文页边 ≥18mm | 家用打印机有不可打印边，太靠边会被裁或触发"缩放适应" |

## 三、本仓已有的自动安全区检查

`scripts/preflight.py` 的**闸门 2** 会逐格式断言「底部净空带必须是纯白」——这正是
上表"底部遮挡区"的可执行版本：任何被挤到页面外的元素都会落在那里，一次字节扫描就能抓到。
各格式的净空高度写在 `FORMATS` 里（A4/朋友圈/方形 60px、横版 30px、易拉宝 240px）。

> 想给某个平台加更严的安全区？改 `FORMATS` 里该格式的净空值即可，闸门自动生效。
