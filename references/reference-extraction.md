# 参考图 → 确定性复刻

> 竞品 poster-style-transfer 的原则说得好：**Extract poster grammar, not poster content.**
> （提取海报的"语法"，而不是抄海报的"内容"。）
>
> 区别在于做法：它靠模型"看"图写一段提示词；本仓用**可测量的方式**给出色板、版面结构、
> 比例与建议格式，并画一张**带标注的叠加图**供人核验。

## 一、什么时候用

- 客户发来一张"就照这个感觉做"的参考图；
- 你想复用一个喜欢的版式，但**必须替换掉**其中的人物、文字、logo、商品、场景；
- 需要把一张参考图的设计规律，落到本仓的产线（`data.typ` + `tokens.typ` + 模板）上。

## 二、用法

```bash
python scripts/analyze_reference.py --image 参考图.jpg --out out/ref --name myref
```

产物（都在 `--out` 目录）：

| 文件 | 用途 |
|---|---|
| `myref-analysis.png` | **带标注的结构叠加图**：横带（红框）+ 竖栏（蓝线）+ 色卡 —— 先目视核验检测对不对 |
| `myref-report.md` | 人读报告：比例、建议格式、色板表（含 WCAG 对比度）、横带/竖栏结构表 |
| `myref-palette.typ` | 可直接粘进 `example/lib/styles.typ` 的**配色片段**（候选风格） |

## 三、完整工作流

```
参考图
  ↓ scripts/analyze_reference.py
叠加图（核验检测） + 报告（色板/结构/比例）
  ↓ 人工校订色板（脚本是启发式，不是终审）
粘进 lib/styles.typ  →  preflight 的对比度闸门自动校验
  ↓ 按结构表新建 templates/poster-*.typ（数据仍来自 lib/data.typ）
渲染 → 预检双闸 → 目视验收 → 交付
```

## 四、本地图也能验（往返测试）

拿本仓自己的成品当参考图跑一遍，应该能**还原出品牌色与主要横带**——这是验证脚本是否
正常工作最快的办法：

```bash
python scripts/analyze_reference.py --image example/out/poster-social.png --name roundtrip
```

> 实测：`poster-social.png` → 比例 0.750 → 建议 `poster-social`；`brand` 精确还原为
> `#1B4F8C`；横带检测把标题两行 / 强调线 / 导语 / 亮点三条 / 信息两行 / 报名区 / 页脚
> 全部正确圈出。

## 五、诚实边界（务必知道）

- **色板是启发式推断，不是终审**：量化会把**小面积色**（如点缀色、灰字）合并掉，
  所以 `tint` / `muted` 常常不准，报告里写了「务必人工校订」。
  拿到片段后跑一次 `preflight.py`，对比度闸门会告诉你改没改对。
- **只给"语法"，不给"实现"**：报告给的是百分比的横带/竖栏，不生成像素级复刻——真正的
  版式仍要人（或 agent）在模板里重写。这是刻意设计：抄像素会连带抄内容与版权风险。
- **色彩/构图不受版权保护，但**：人物肖像、logo、商标、具体插画、独特文案**受保护**，
  必须替换。别做像素级重绘，别描摹独特插画，确认你对参考图有使用权。

## 六、和竞品的差异

| | poster-style-transfer（56★）| 本仓 |
|---|---|---|
| 提取方式 | 模型读图 → 一段英文提示词 | **脚本量化 + 结构分析**（可复现）|
| 产物 | Style Spec 文本 | 叠加图 + 报告 + 可粘的 Typst 片段 |
| 可核验性 | 靠"看着像不像" | **叠加图能逐带核对** |
| 落地产线 | 提示词再生成 | **直接进本仓的确定性渲染产线** |
